🔹 Overview
This project analyzes the economic and social impacts of wars and conflicts using structured datasets.
The current stage focuses on data import, cleaning, preprocessing, and exploratory analysis in Google Colab.
Future stages will extend into Power BI dashboards with interactive KPI cards and slicers

🔹 Current Progress
Imported dataset into Google Colab.
Cleaned and standardized fields (GDP, inflation, poverty, unemployment, costs, informal economy).
Conducted exploratory analysis to identify patterns and anomalies.
Prepared the dataset for later visualization in Power BI.
